Collie LSP brings diagnostics, completion, navigation, formatting, and safe refactoring to .y files in any LSP-compatible editor.

Put Collie on grammar duty.

Ruby 3.2 or newer is required.

  1. 1

    Install the server

    gem install collie-lsp
  2. 2

    Connect your editor

    Run collie-lsp --stdio from VS Code, Neovim, Emacs, Vim, or another LSP client.

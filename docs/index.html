collie-lsp

Language server for Lrama-style BNF grammar files.

gem install collie-lsp

Ruby 3.2+MITv0.1.0

%%

Language features

  • DiagnosticsLint errors and style violations as you type.
  • CompletionTokens, nonterminals, and grammar keywords.
  • NavigationDefinitions, references, symbols, and hover details.
  • RefactoringValidated symbol renaming and quick fixes.
  • FormattingConfigurable indentation, alignment, and line length.
  • StructureSemantic highlighting, outlines, and folding.

Editor setup

Configure your LSP client to start:

collie-lsp --stdio

VS Code, Neovim, Emacs, Vim, and other LSP-compatible editors are supported.
